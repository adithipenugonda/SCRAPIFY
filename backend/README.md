Scrapify Backend

Scrapify is a smart Waste-to-Wealth backend platform designed to simplify household scrap collection and recycling management. The system enables users to schedule scrap pickups, track recycling activity, earn green reward points, and monitor their environmental impact. Along with user functionality, the platform also includes dedicated modules for collectors and administrators, creating a complete ecosystem for waste management operations.

The backend is built using Node.js, Express.js, and MongoDB with a scalable and modular architecture. It supports JWT-based authentication, role-based authorization, pickup lifecycle management, dashboard analytics, live scrap pricing, reward systems, profile management, file uploads, and transaction handling.

The project follows a production-style backend structure with separate layers for models, controllers, routes, middleware, validations, and utility functions, making the codebase clean, maintainable, and scalable for future enhancements.
