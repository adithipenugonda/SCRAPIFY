# Scrapify

Scrapify is a smart waste management and recycling platform designed to simplify the process of scrap collection while promoting sustainable environmental practices. The system connects users, scrap collectors, and administrators through a single digital platform that enables efficient waste handling, live scrap pricing, and environmental impact tracking.

The platform focuses on converting household and industrial waste into reusable resources while rewarding users for responsible recycling behavior.

---

# System Overview

The system operates through three major roles:

* User
* Collector
* Admin

Each role has a dedicated interface and separate responsibilities within the platform.

---

# User Module

The User module allows individuals to schedule scrap pickups directly from their homes. Users can select different scrap categories such as paper, plastic, iron, cardboard, glass, or e-waste and provide pickup details.

Once a request is submitted, the system assigns the pickup request to available collectors based on availability and operational workflow.

Users can also monitor their recycling history, track pickup requests, and view live scrap market prices. The platform additionally calculates environmental contributions such as carbon reduction and recycled waste statistics.

The reward system encourages users to recycle more frequently by awarding green points based on the quantity and type of scrap submitted.

---

# Collector Module

The Collector module is designed for scrap collection personnel. Collectors receive pickup requests from users and can accept or manage assigned jobs through a dedicated dashboard.

The dashboard provides information about:

* available jobs
* pickup locations
* estimated earnings
* completed pickups
* route tracking
* live work status

Collectors can manage daily operations efficiently while monitoring their total earnings and performance metrics.

The collector interface is inspired by modern delivery and logistics applications to provide a professional operational experience.

---

# Admin Module

The Admin module manages the complete platform ecosystem. Administrators monitor all users, collectors, pickup requests, and scrap pricing information.

The admin dashboard provides system-level analytics and operational insights, including:

* total users
* active collectors
* completed pickups
* recycling performance
* platform statistics

Administrators also manage live scrap prices to ensure users receive updated market values for recyclable materials.

---

# Authentication and Security

The system uses role-based authentication to provide secure access control for different users.

Each user type receives separate dashboard access after login. Authentication tokens are used to maintain secure sessions and protect sensitive routes within the platform.

The platform ensures that only authorized users can access role-specific functionalities.

---

# Pickup Management Workflow

The pickup process begins when a user schedules a scrap collection request.

The system stores the request and makes it available to collectors. Once a collector accepts the request, the pickup status changes dynamically and becomes trackable by the user.

After collection is completed:

* the pickup history is updated
* collector earnings are calculated
* user reward points are generated
* environmental impact metrics are updated

This creates a complete waste management lifecycle within the platform.

---

# Live Scrap Price System

The platform includes a live market pricing section that displays current scrap values for different recyclable materials.

Prices are categorized based on material type and are visually represented using modern market-style cards. The system is designed to help users understand the value of recyclable waste before scheduling pickups.

The pricing interface improves transparency and builds trust between users and collectors.

---

# Environmental Impact Tracking

Scrapify tracks the collective environmental contribution generated by users through recycling activities.

The system displays:

* total waste recycled
* carbon emission reduction
* environmental savings
* community impact statistics

A leaderboard mechanism can also be integrated to encourage healthy competition among users and improve recycling participation.
